# Book Management System

Spring Boot 图书管理系统 - 使用 MySQL + Redis + Maven 构建的完整后端解决方案。

## 项目简介

这是一个基于 Spring Boot 的图书管理系统，集成了 MySQL 数据库和 Redis 缓存，提供完整的 RESTful API 接口。

## 技术栈

- **框架**: Spring Boot 3.x
- **数据库**: MySQL 8.0+
- **缓存**: Redis 6.0+
- **构建工具**: Maven 3.6+
- **JDK**: Java 11+

## 功能特性

- ✅ 完整的图书 CRUD 操作
- ✅ Redis 缓存集成
- ✅ 统一异常处理
- ✅ 数据验证
- ✅ RESTful API 设计
